# Apphive

> Apphive is a no-code / AI-assisted platform for building native iOS and Android mobile applications without writing code. A visual drag-and-drop editor with live phone previews lets makers assemble screens and logic, wire in native device capabilities (GPS/maps, push notifications, camera, authentication, databases, in-app purchases), connect third-party APIs and payment gateways (Stripe, Openpay), and compile and publish finished apps to the Apple App Store and Google Play. Apphive is backed by 500 Global.

Apphive is a company profile in the API Evangelist network. It publishes no first-party developer REST API or OpenAPI definition; its "API" surface is inside the builder — custom integrations, cloud functions, and webhooks that the apps you build consume.
